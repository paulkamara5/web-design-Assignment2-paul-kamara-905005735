# TasteHub Restaurant Website

A responsive five-page restaurant website built with HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `menu.html` — Menu
- `about.html` — About
- `reservations.html` — Reservations
- `contact.html` — Contact

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a web browser.
3. Use the navigation to visit the other pages.

All images and the TasteHub SVG logo are stored locally in `images/`.
The reservation and contact forms demonstrate front-end submission feedback only. They do not send messages to a restaurant server.

## GitHub
Create a new GitHub repository, upload the contents of this folder, and enable GitHub Pages from Settings → Pages to publish the site.
